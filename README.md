# Learn How To Code

A structured programming-learning repository that combines fundamentals, exercises, and complete projects across Python, C#, Kotlin, Git/GitHub, development environments, data structures, and algorithms.

The goal is not only to collect syntax examples, but to build a progressively stronger software-development foundation through:

- explanations;
- runnable examples;
- practice tasks;
- reference solutions;
- progressively larger projects;
- repository hygiene;
- debugging and validation; and
- professional documentation.

## Repository standards

The repository follows these principles:

- source code should be runnable or clearly marked as pseudocode/reference material;
- project READMEs should match the actual files in the repository;
- credentials, secret keys, and private configuration should not be committed;
- generated caches and build output should not be tracked;
- examples should favor explicit validation and readable structure;
- beginner explanations should remain technically accurate; and
- projects should document what is complete versus what is planned.

## How to use this repository

A productive study cycle is:

1. read the lesson README;
2. study the notes;
3. type and run examples;
4. complete the tasks without looking at the solutions;
5. compare with reference solutions;
6. modify the examples;
7. build a small project;
8. commit progress with a descriptive Git message.
