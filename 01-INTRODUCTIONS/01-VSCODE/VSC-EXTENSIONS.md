# Recommended VS Code Extensions for Python

## Core extensions

### Python — Microsoft

Extension ID: `ms-python.python`

Provides Python language support, interpreter selection, debugging, testing integration, and environment discovery.

### Pylance — Microsoft

Extension ID: `ms-python.vscode-pylance`

Provides fast IntelliSense, type analysis, navigation, and diagnostics.

### Black Formatter — Microsoft

Extension ID: `ms-python.black-formatter`

Formats Python code consistently.

### Ruff — Astral Software

Provides fast linting and code-quality checks.

### Jupyter — Microsoft

Extension ID: `ms-toolsai.jupyter`

Adds notebook support for data analysis, experimentation, and learning.

## Helpful optional extensions

### GitLens

Adds richer Git history, blame, and repository insights.

### GitHub Pull Requests and Issues

Useful for reviewing and managing GitHub collaboration directly from VS Code.

### GitHub Copilot

Optional AI coding assistance. Use generated suggestions as material to review and understand rather than as a substitute for learning.

## Extension guidance

Do not install extensions only because they are popular. Prefer tools that solve a real need in your workflow, and periodically remove extensions you no longer use.
