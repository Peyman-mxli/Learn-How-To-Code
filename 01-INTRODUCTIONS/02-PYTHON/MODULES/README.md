## Lesson structure

A complete lesson normally contains:

- README.md — scope, objectives, prerequisites, and navigation;
- NOTES.py.py.py.py.py.py.py.py.py — detailed explanations and annotated code;
- EXAMPLES.py.py.py.py.py.py.py.py.py — focused programs to run and modify;
- TASKS.py.py.py.py.py.py.py.py.py — exercises arranged by difficulty; and
- TASKS.py.py.py.py.py.py.py.py.py-SOLUTIONS — reference solutions to review after attempting the tasks.

Some parent folders act as indexes and link to smaller lessons rather than duplicating every file type.

## Recommended study workflow

1. Read the module README.
2. Study the notes and type the important examples.
3. Run the example programs and change their inputs.
4. Complete the tasks without opening the solutions.
5. Compare results with the reference solutions.
6. Refactor for clarity, correctness, and style.
7. Apply the topic in a small independent program.
8. Commit completed work with a descriptive Git message.

## Prerequisites

Before beginning, learners should be able to:

- run Python from a terminal;
- create and execute a Python file;
- use a code editor such as Visual Studio Code;
- recognize basic command-line paths; and
- save work with Git and GitHub.

Start with the repository's [Python introduction](../) if the development environment is not ready.
