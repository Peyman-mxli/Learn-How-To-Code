# Control Flow in Python

This lesson introduces the mechanisms that determine which statements run, when they run, and how often they run. It serves as the overview for the specialized control-flow lessons that follow.

## Learning objectives

After completing this lesson, learners will be able to:

- make decisions with if, elif, and else;
- repeat operations with for and while loops;
- change loop behavior with break, continue, and pass;
- control function execution with return, yield, and raise;
- handle expected failures with try and except;
- manage resources safely with context managers;
- use match and case in Python 3.10 or newer;
- write readable comprehensions and conditional expressions; and
- choose an appropriate control-flow construct for a problem.

## Topics covered

| Topic | Purpose |
|---|---|
| Conditional statements | Select one execution path from multiple possibilities |
| for loops | Iterate over sequences and other iterable objects |
| while loops | Repeat while a condition remains true |
| Loop-control statements | Exit, skip, or reserve an incomplete code block |
| Exception handling | Respond safely to runtime errors |
| Context managers | Guarantee setup and cleanup of managed resources |
| Function flow | Return results, generate values lazily, or signal errors |
| Pattern matching | Express structured multi-branch decisions |
| Comprehensions | Build collections through concise iteration |
| Conditional expressions | Select a value with a compact inline condition |
