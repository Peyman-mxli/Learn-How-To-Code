# Programming Foundations

A structured collection of beginner-to-intermediate learning materials covering development environments, programming languages, version control, data structures, algorithms, and practical software-development workflows.

## Learning path

| # | Topic | Focus |
|---:|---|---|
| 01 | [Visual Studio Code](./01-VSCODE/) | Editor setup and Python workflow |
| 02 | [Python](./02-PYTHON/) | Python fundamentals through testing/debugging |
| 03 | [Git and GitHub](./03-GITHUB/) | Version control, branches, PRs, conflicts, Actions |
| 04 | [Unicode, Symbols & Emojis](./04-EMOJIS/) | Unicode and console output |
| 05 | [C#](./05-CSHARP/) | Fundamentals through professional .NET architecture |
| 06 | [Visual Studio](./06-VISUALSTUDIO/) | .NET IDE setup |
| 07 | [Data Structures](./07-DATA-STRUCTURES/) | Arrays, lists, queues, stacks, trees, maps, sets, heaps, graphs |
| 08 | [Algorithms](./08-ALGORITHMS/) | Searching, sorting, complexity, graph/DP techniques |
| 09 | [IntelliJ IDEA](./09-INTELLIJ/) | IDE, JDK, Kotlin project, debugging |
| 10 | [Kotlin](./10-KOTLIN/) | Complete Kotlin foundations path |

## Recommended routes

**Python:** VS Code → Python → Git/GitHub  
**C# / CS:** C# → Visual Studio → Data Structures → Algorithms  
**Kotlin:** Git/GitHub → IntelliJ IDEA → Kotlin

## Study method

1. Read the topic README.
2. Study notes.
3. Run and modify examples.
4. Complete tasks independently.
5. Review solutions.
6. Build a small project.
7. Commit the work with a descriptive Git message.
