# First Kotlin Project in IntelliJ IDEA

This lesson creates, runs, and verifies a first Kotlin/JVM application in IntelliJ IDEA.

## Learning objectives

Learners will create a Kotlin project, select a JDK, choose a build system, understand its structure, create source, run a program, read output, and diagnose common problems.

## Prerequisites

1. [IntelliJ IDEA installation](../01-INSTALLATION-AND-SETUP/)
2. [JDK installation and configuration](../02-JDK-INSTALLATION-AND-CONFIGURATION/)

## Project result

~~~kotlin
fun main() {
    println("Hello from IntelliJ IDEA!")
}
~~~

Expected:

~~~text
Hello from IntelliJ IDEA!
~~~

## Completion criteria

- [ ] Kotlin project opens.
- [ ] Correct JDK is selected.
- [ ] Main.kt is under a source root.
- [ ] Main is recognized.
- [ ] Program runs.
- [ ] Expected output and exit code appear.
- [ ] Modified code reruns.
- [ ] No secrets are stored.
