# IntelliJ IDEA — Installation and Setup

A practical beginner lesson for installing IntelliJ IDEA, completing the first launch, and verifying that the IDE is ready for later Java and Kotlin configuration.

> This lesson installs and verifies IntelliJ IDEA itself. JDK configuration and the first runnable JVM project will be covered in the next stage.

## Learning objectives

After completing this lesson, learners will be able to:

- explain what IntelliJ IDEA is;
- distinguish free core functionality from subscription features;
- verify that a computer meets current installation requirements;
- select an installation method;
- install IntelliJ IDEA on Windows, macOS, or Linux;
- complete the initial startup screens safely;
- manage themes, updates, and plugins responsibly;
- verify the installed version; and
- diagnose common installation problems.

## Current product model

JetBrains presents IntelliJ IDEA as a unified product. Core Java and Kotlin features are available at no cost, while advanced functionality may require an Ultimate subscription. JetBrains also provides access to the open-source Community Edition.

The free functionality is sufficient for this learning repository.

Official resources:

- [Download IntelliJ IDEA](https://www.jetbrains.com/idea/download/)
- [Install IntelliJ IDEA](https://www.jetbrains.com/help/idea/installation-guide.html)
- [JetBrains Toolbox App](https://www.jetbrains.com/toolbox-app/)

## Completion criteria

This lesson is complete when:

- [ ] the correct installer was obtained from JetBrains;
- [ ] IntelliJ IDEA launches without an installation error;
- [ ] the Welcome screen appears;
- [ ] the installed version and operating system are recorded;
- [ ] Settings and Plugins can be opened;
- [ ] the learner understands which features are free; and
- [ ] sufficient disk space remains for projects, SDKs, and build files.

## Recommended workflow

1. Read Notes.md.
2. Follow the matching operating-system procedure.
3. Complete the guided checks in Examples.md.
4. Perform every activity in Tasks.md.
5. Compare the results with Tasks_Solutions.md.
6. Save installation evidence in personal study notes.
