# Installation and Setup — Reference Solutions

Hardware, operating-system, version, and reflection answers vary.

## Task 1

1. IDE means **Integrated Development Environment**.
2. JetBrains develops IntelliJ IDEA.
3. IntelliJ IDEA is an IDE, not a programming language.
4. Tools include a code editor, debugger, project explorer, terminal, build integration, and version control.

## Task 2

Free core Java and Kotlin functionality is sufficient here. Ultimate may be necessary for specific enterprise, framework, database, or advanced web features. Official information must be checked because packaging and licensing can change.

## Task 3

A valid comparison uses the current official baseline: four-core x86_64 or ARM64 CPU, 8 GB RAM, 10 GB available disk space, 1280 × 720 display, and a supported operating system.

## Task 4

Toolbox is appropriate for managing multiple JetBrains applications and updates. Standalone installation is appropriate when a specific release is required or organizational policy controls deployment.

## Task 5

The expected source is the official JetBrains website, with the correct operating system and architecture selected.

## Task 6

The expected result is a completed installation from which IntelliJ IDEA launches.

## Task 7

For a new installation, **Do not import settings** is normally appropriate. Review all choices, choose an accessible theme, avoid unnecessary plugins, and reach Welcome.

## Task 8

Copy the exact version and build from **Help → About**. Record no secrets, tokens, or license keys.

## Task 9

Welcome should provide New Project, Open, Get from VCS, Settings or Customize, and Plugins. Labels can vary slightly.

## Task 10

The learner should locate the four requested settings areas. No changes are required.

## Task 11

The computer is below both baselines: 4 GB is less than 8 GB RAM, and 6 GB is less than 10 GB disk space. Memory and available storage must be increased or another suitable computer used.

## Task 12

A complete answer evaluates publisher, purpose, compatibility, maintenance, and actual need. **Do not install** is valid when built-in functionality is sufficient.

## Task 13

A reasonable recovery sequence is:

1. record the exact error;
2. restart;
3. confirm system compatibility;
4. verify disk space and permissions;
5. launch without a large project;
6. investigate problematic third-party plugins;
7. consult JetBrains documentation; and
8. request help using the exact version, OS, and error.

## Final outcome

The lesson is complete when IntelliJ IDEA launches, Welcome is accessible, the version is recorded, and the learner understands that JDK configuration remains.
