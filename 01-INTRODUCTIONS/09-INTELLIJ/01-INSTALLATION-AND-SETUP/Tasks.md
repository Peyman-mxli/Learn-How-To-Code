# Installation and Setup Tasks

Complete these activities in order. Do not commit private computer information, account details, or license data.

## Rank 1 — Knowledge

### Task 1

Answer:

1. What does IDE stand for?
2. Who develops IntelliJ IDEA?
3. Is IntelliJ IDEA a programming language?
4. Name four tools integrated into an IDE.

### Task 2

Explain which functionality is sufficient for this repository, when Ultimate may be needed, and why the official site should be checked.

## Rank 2 — Preparation

### Task 3

Record the operating-system support status, CPU architecture, total RAM, available disk space, and display resolution. Compare them with JetBrains requirements and conclude **Ready** or **Not ready**.

Do not publish unique device identifiers.

### Task 4

Choose Toolbox or standalone installation. Explain the choice.

## Rank 3 — Installation

### Task 5

Use the official JetBrains website, confirm the operating system and architecture, and record the source URL. Do not use an unofficial mirror.

### Task 6

Install IntelliJ IDEA and record only non-sensitive evidence such as installation method and completion date.

### Task 7

Review import settings, privacy, license, and theme options. Reach the Welcome screen without adding unnecessary plugins.

## Rank 4 — Verification

### Task 8

Open **Help → About** and record:

| Field | Your result |
|---|---|
| IntelliJ IDEA version | |
| Build number | |
| Operating system | |
| Installation method | |
| Verification date | |

Never record license keys or account tokens.

### Task 9

Confirm:

- [ ] New Project
- [ ] Open
- [ ] Get from VCS
- [ ] Settings or Customize
- [ ] Plugins

### Task 10

Locate Appearance, Plugins, Version Control, and Updates in Settings. Do not change settings without understanding them.

## Rank 5 — Troubleshooting

### Task 11

A computer has 4 GB RAM and 6 GB free disk space. Explain why it fails the baseline and what must improve.

### Task 12

Research one optional Marketplace plugin without installing it. Record its publisher, purpose, compatibility, maintenance evidence, and necessity.

### Task 13

Write a recovery procedure for an installation that completes but does not launch.

## Final checklist

- [ ] I used an official source.
- [ ] My computer meets the baseline.
- [ ] IntelliJ IDEA launches.
- [ ] I can reach Welcome.
- [ ] I recorded the version.
- [ ] Settings and Plugins open.
- [ ] I understand that JDK configuration is next.
- [ ] I protected private information.
