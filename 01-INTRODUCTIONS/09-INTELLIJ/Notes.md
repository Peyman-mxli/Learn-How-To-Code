# IntelliJ IDEA — Aggregate Notes

IntelliJ IDEA combines editing, project navigation, build/run configurations, debugging, terminal access, version control, refactoring, and plugin support in one IDE.

## Key concepts

- **Project window**: files and folders.
- **Editor**: code writing and inspection.
- **Run tool window**: program output.
- **Debugger**: breakpoints, step over, step into, resume, variable inspection.
- **Terminal**: shell access inside the IDE.
- **Version Control**: Git status, diffs, commits, branches, merge-conflict tools.
- **Refactoring**: safe structural changes that update references.

Use the numbered folders for detailed instructions.
