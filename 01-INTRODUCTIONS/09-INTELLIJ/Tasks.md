# IntelliJ IDEA — Aggregate Tasks

1. Install IntelliJ IDEA.
2. Configure a JDK.
3. Create a Kotlin console project.
4. Run the application.
5. Open the built-in terminal and run `git --version` and `git status`.
6. Set a breakpoint and inspect a variable in Debug mode.
7. Rename a symbol using the refactor command.
8. Format the current file.
9. Clone or open a Git repository.
10. Describe the difference between Run and Debug.

Complete the detailed task files inside the numbered lessons for full practice.
