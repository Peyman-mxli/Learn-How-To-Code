# IntelliJ IDEA — Aggregate Task Solutions

These are high-level checks for the aggregate tasks.

1. IntelliJ opens successfully.
2. A valid JDK is visible in project settings.
3. The Kotlin project contains a runnable source file.
4. Program output appears in the Run tool window.
5. The terminal reports a Git version and repository status.
6. Debug mode pauses on the breakpoint and shows variable values.
7. Refactor Rename updates references consistently.
8. Code formatting follows the IDE formatter.
9. Git history/status is visible through the IDE or terminal.
10. Run executes normally; Debug executes with debugging controls and inspection.

For step-by-step solutions, use the lesson-specific `Tasks_Solutions.md` files.
