# IntelliJ IDEA — Aggregate Examples

Use these examples as a quick reference after completing the numbered IntelliJ lessons.

## Common actions

- **New Project**: create a project from the Welcome screen.
- **Run**: use the green run icon or the configured run shortcut.
- **Debug**: set a breakpoint, start Debug, and inspect variables.
- **Terminal**: open the Terminal tool window and run commands such as `git status`.
- **Refactor**: use Rename and other refactor tools instead of manual search-and-replace.
- **Search Everywhere**: use IntelliJ's global search to locate files, symbols, settings, and actions.

For detailed walkthroughs, use the numbered lesson folders.
