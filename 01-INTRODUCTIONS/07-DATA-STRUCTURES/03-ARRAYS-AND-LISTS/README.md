# 🧵 03 – Arrays and Lists

Welcome to the third part of the Data Structures module in my Learn-How-To-Code journey! In this section, I will learn about **Arrays** and **Lists**, two of the most commonly used data structures in C#.

Arrays provide a fixed-size collection that stores elements of the same type in contiguous memory locations. Lists offer similar functionality but with the advantage of dynamic sizing, allowing elements to be added or removed as needed.

Understanding the differences between arrays and lists will help me choose the most appropriate structure depending on the requirements of a problem.
