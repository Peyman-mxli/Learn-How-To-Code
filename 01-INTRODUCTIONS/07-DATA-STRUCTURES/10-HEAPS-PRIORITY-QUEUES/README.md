# Heaps and Priority Queues

A priority queue returns items by priority rather than insertion order. Heap-based implementations support efficient insertion and priority removal.

## Learning objectives

- understand the core model and operations;
- identify appropriate use cases;
- discuss basic performance trade-offs;
- implement and use the structure in C#.
