# Linked Lists

A linked list stores elements in nodes connected by references. It is useful when insertion/removal patterns matter more than direct indexed access.

## Learning objectives

- understand the core model and operations;
- identify appropriate use cases;
- discuss basic performance trade-offs;
- implement and use the structure in C#.
