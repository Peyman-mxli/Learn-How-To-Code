# 🧵 Dictionaries in C#

## Overview

In this module, I will learn about dictionaries in C#.

A dictionary is a collection that stores data as **key-value pairs**. Each key must be unique and is used to quickly access its associated value.

Dictionaries are commonly used when I need to associate one piece of information with another, such as:

- Names and phone numbers
- Usernames and passwords
- Product IDs and product names
- Configuration settings
- Student IDs and grades

C# provides the generic `Dictionary<TKey, TValue>` class inside the `System.Collections.Generic` namespace.

---

## What I Will Learn

By completing this module, I will learn how to:

- Understand key-value pairs.
- Create dictionaries using `Dictionary<TKey, TValue>`.
- Add elements using `Add()`.
- Add or update elements using direct assignment.
- Access values using keys.
- Verify whether a key exists using `ContainsKey()`.
- Remove elements using `Remove()`.
- Iterate through dictionaries.
- Use dictionaries in real-world applications.

Dictionaries are more advanced than arrays and lists because they use keys instead of numeric positions.

Instead of asking:

> "What is stored at index 2?"

I can ask:

> "What value belongs to this key?"

This makes searching much faster.
