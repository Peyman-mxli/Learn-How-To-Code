# 🧵 Stacks in C#

## Overview

In this module, I will learn about stacks in C# and how they implement the LIFO (Last In, First Out) principle.

A stack is a linear data structure where the last element added is the first element removed. It works like a stack of plates: I can only add or remove items from the top.

C# provides the generic `Stack<T>` class in the `System.Collections.Generic` namespace, allowing me to work with stacks efficiently and safely without implementing them from scratch.

---

## What I Will Learn

By completing this module, I will learn how to:

- Understand the LIFO (Last In, First Out) principle.
- Create stacks using `Stack<T>`.
- Add elements using `Push()`.
- Remove elements using `Pop()`.
- View the top element using `Peek()`.
- Check whether a stack is empty using `Count`.
- Remove all elements using `Clear()`.
- Iterate through a stack.
- Use stacks to solve real-world problems.
- Build simple applications based on stack behavior.
