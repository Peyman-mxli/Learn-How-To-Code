# Graphs

A graph models relationships between vertices using edges. Graphs represent networks, routes, dependencies, social connections, and many other systems.

## Learning objectives

- understand the core model and operations;
- identify appropriate use cases;
- discuss basic performance trade-offs;
- implement and use the structure in C#.
