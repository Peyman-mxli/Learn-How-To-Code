# Data Structures

Data structures organize and store information so software can access and modify it efficiently.

This module uses C# examples and connects each structure to practical trade-offs such as access time, insertion cost, ordering, memory usage, and typical use cases.

## Learning goals

By completing the module, I can:

- explain why different structures exist;
- select a structure based on operations and constraints;
- discuss basic time/space trade-offs;
- implement common structures in C#; and
- connect data structures to algorithms.
