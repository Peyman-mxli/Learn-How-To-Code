# 🧵 07 – Data Structures

Welcome to the seventh module of my Learn-How-To-Code journey! In this module, I will explore the fundamental concepts of **Data Structures** and understand why they are essential in software development. Data structures allow programmers to organize, store, process, and retrieve information efficiently.

I will learn that choosing the right data structure depends on the problem I want to solve. Just as there are different ways to organize clothes in a closet, there are different ways to organize data in memory. Each approach has advantages and disadvantages regarding speed, memory usage, and ease of modification.

This module introduces the foundations of Data Structures through concepts such as linear and non-linear structures, arrays, linked lists, stacks, queues, Abstract Data Types (ADTs), and **Recursion**. I will also discover how C# uses abstract classes to represent abstract concepts and enforce common behavior among related objects. Finally, I will learn how recursive methods solve problems by calling themselves until a stopping condition is reached.

---

## 🎯 What I Will Learn

By the end of this module, I will be able to:

* Understand what a data structure is and why it is important.
* Explain how data structures differ from databases and files.
* Distinguish between linear and non-linear data structures.
* Describe the characteristics of arrays.
* Explain how linked lists work.
* Understand the behavior of stacks (LIFO).
* Understand the behavior of queues (FIFO).
* Define what an Abstract Data Type (ADT) is.
* Implement Abstract Data Types using abstract classes in C#.
* Create classes that inherit from abstract classes.
* Understand what recursion is.
* Identify the base case and recursive case of a recursive method.
* Solve problems using recursion.
* Calculate factorials recursively.
* Generate Fibonacci sequences recursively.
* Practice object-oriented principles through real examples.
