# 🧵 Queues in C#

## Overview

In this module, I will learn about queues in C# and how they implement the FIFO (First In, First Out) principle.

A queue is a linear data structure where the first element added is the first element removed. It works just like a real-life line of people waiting for service.

C# provides the generic `Queue<T>` class in the `System.Collections.Generic` namespace, allowing me to work with queues efficiently and safely.

---

## What I Will Learn

By completing this module, I will learn how to:

- Understand the FIFO (First In, First Out) principle.
- Create queues using `Queue<T>`.
- Add elements using `Enqueue()`.
- Remove elements using `Dequeue()`.
- View the next element using `Peek()`.
- Check the number of elements using `Count`.
- Remove all elements using `Clear()`.
- Iterate through queues.
- Apply queues to solve real-world problems.
- Build simple queue-based applications.
