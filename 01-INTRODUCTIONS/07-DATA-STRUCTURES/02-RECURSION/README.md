# 🧵 02 – Recursion

Welcome to the second part of the Data Structures module in my Learn-How-To-Code journey! In this section, I will learn about **Recursion**, a programming technique where a method calls itself to solve a problem.

Recursion is useful when a problem can be divided into smaller versions of the same problem. Instead of solving everything at once, a recursive method solves a small part and keeps calling itself until it reaches a stopping condition.

In this part, I will study recursive methods, base cases, recursive cases, factorial calculations, Fibonacci sequences, and recursive range summation using C#.

---

## 🎯 What I Will Learn

By the end of this part, I will be able to:

* Understand what recursion is.
* Explain why recursion is useful.
* Identify the base case of a recursive method.
* Identify the recursive case of a recursive method.
* Understand what causes a Stack Overflow error.
* Calculate factorials using recursion.
* Generate Fibonacci numbers using recursion.
* Trace recursive calls step by step.
* Solve a range-sum problem recursively.
* Practice recursive thinking in C#.
