# 🧵 Trees in C#

## Overview

In this module, I will learn about trees in C#.

A tree is a hierarchical data structure made of nodes. Each node can have child nodes, and the first node is called the root.

Trees are used to represent data with levels, such as:

- File systems
- Databases
- Family trees
- Organization charts
- Search systems

---

## What I Will Learn

By completing this module, I will learn how to:

- Understand tree structure.
- Identify the root node.
- Identify leaf nodes.
- Identify internal nodes.
- Understand levels in a tree.
- Understand the degree of a node.
- Understand binary trees.
- Create tree nodes in C#.
- Insert values into a binary search tree.
- Traverse a tree using Inorder, Preorder, and Postorder.
- Search for values inside a tree.
- Calculate the height of a tree.
