# Merging

Merging combines committed work from one branch into another.

## Core commands / actions

```bash
git switch main
git merge feature/example
```

## Practice

1. Reproduce the workflow in a disposable practice repository.
2. Run `git status` before and after each major step.
3. Read command output instead of copying commands blindly.
4. Confirm the resulting history with `git log --oneline --graph --decorate`.
