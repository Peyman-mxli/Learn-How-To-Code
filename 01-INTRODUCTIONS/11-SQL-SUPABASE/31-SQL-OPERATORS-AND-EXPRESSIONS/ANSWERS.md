# Class 31 — Answer Explanations

[Lesson](./README.md) · [Questions](./QUESTIONS.md)

## Answer 1

**Question:** What does CASE do?

**Explanation:** It computes a value using conditions evaluated in order.

## Answer 2

**Question:** What is the meaning of WHEN?

**Explanation:** It introduces a condition in a CASE expression.

## Answer 3

**Question:** What does THEN provide?

**Explanation:** The result expression when the WHEN condition is true.

## Answer 4

**Question:** What is ELSE?

**Explanation:** The fallback if no earlier condition matches.

## Answer 5

**Question:** What does IS NULL test?

**Explanation:** Whether the value is SQL NULL.

## Answer 6

**Question:** Why is = NULL incorrect?

**Explanation:** Comparisons with NULL evaluate to UNKNOWN; use IS NULL.

## Answer 7

**Question:** What is BETWEEN?

**Explanation:** Inclusive range comparison.

## Answer 8

**Question:** What is IN?

**Explanation:** Membership among given values.

## Answer 9

**Question:** What does ILIKE do?

**Explanation:** Case-insensitive pattern matching in PostgreSQL.

## Answer 10

**Question:** What does >= mean?

**Explanation:** Greater than or equal to.
