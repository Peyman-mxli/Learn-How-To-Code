# Class 33 — Answer Explanations

[Lesson](./README.md) · [Questions](./QUESTIONS.md)

## Answer 1

**Question:** What is the CLI?

**Explanation:** A command-line interface to manage local Supabase development and associated workflows.

## Answer 2

**Question:** What does supabase init do?

**Explanation:** Initialize Supabase project configuration in the current working directory.

## Answer 3

**Question:** What does supabase start do?

**Explanation:** Start supported local Supabase services with required tooling.

## Answer 4

**Question:** What is a migration file?

**Explanation:** Version-controlled SQL representing a database change.

## Answer 5

**Question:** Why use a timestamped migration?

**Explanation:** To preserve an ordered history of changes.

## Answer 6

**Question:** What does db reset do locally?

**Explanation:** Rebuild the local database from migrations and seeds; it can delete existing local data.

## Answer 7

**Question:** What is a seed file?

**Explanation:** Repeatable demonstration data for a test database.

## Answer 8

**Question:** Why keep migrations in GitHub?

**Explanation:** To review, track, share, and reproduce intended schema changes.

## Answer 9

**Question:** Should you push a migration blindly to production?

**Explanation:** No; review, back up, test and approve the release path.

## Answer 10

**Question:** What does supabase status do?

**Explanation:** Show information about local Supabase services.
