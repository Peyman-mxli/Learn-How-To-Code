# 🧵 02-SORTING-ALGORITHMS

## Overview

Sorting algorithms are used to organize data in a specific order, usually from smallest to largest or from largest to smallest.

In this module, I will learn how sorting works, why sorting is important, and how to implement basic sorting algorithms using C#.

## What I will learn

- What a sorting algorithm is
- Why sorting algorithms are important
- Bubble Sort
- Selection Sort
- Insertion Sort
- Differences between sorting algorithms
- Time complexity basics
- How to implement sorting algorithms in C#
