# Recursive Algorithms

Recursive algorithms solve a problem by reducing it to smaller instances and require a base case to terminate.

## Learning goals

- explain the technique in plain language;
- recognize suitable problem patterns;
- implement a clear C# solution;
- estimate time and space complexity; and
- test edge cases.
