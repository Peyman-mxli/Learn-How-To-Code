# 🧵 01-SEARCHING-ALGORITHMS

## Overview

Searching algorithms are used to find specific data within a collection of elements. They are among the most common algorithms in computer science and are essential for efficient problem solving.

In this module, I will learn how searching algorithms work, when to use them, and how to implement them using C#.

## What I will learn

- What a searching algorithm is
- Why searching algorithms are important
- Linear Search
- Binary Search
- Differences between Linear and Binary Search
- Time complexity basics
- How to implement searching algorithms in C#
