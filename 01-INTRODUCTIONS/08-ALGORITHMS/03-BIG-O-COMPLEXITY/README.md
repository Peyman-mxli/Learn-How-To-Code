# Big-O Complexity

Big-O notation describes how an algorithm's resource usage grows as input size grows. Common classes include O(1), O(log n), O(n), O(n log n), and O(n²).

## Learning goals

- explain the technique in plain language;
- recognize suitable problem patterns;
- implement a clear C# solution;
- estimate time and space complexity; and
- test edge cases.
