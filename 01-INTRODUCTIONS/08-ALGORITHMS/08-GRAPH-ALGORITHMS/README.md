# Graph Algorithms

Graph algorithms process vertices and edges. Breadth-first search explores by layers; depth-first search explores along paths before backtracking.

## Learning goals

- explain the technique in plain language;
- recognize suitable problem patterns;
- implement a clear C# solution;
- estimate time and space complexity; and
- test edge cases.
