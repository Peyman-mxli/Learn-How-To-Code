# Algorithms

An algorithm is a finite, well-defined sequence of steps for solving a problem.

This module develops algorithmic thinking using C# examples and introduces both correctness and efficiency.

## Study workflow

1. Understand the problem and expected output.
2. Write a simple correct solution.
3. Identify time and space complexity.
4. Improve the approach only when needed.
5. Test normal, edge, and invalid cases.
6. Compare alternative algorithms.
