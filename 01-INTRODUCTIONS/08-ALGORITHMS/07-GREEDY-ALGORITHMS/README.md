# Greedy Algorithms

A greedy algorithm repeatedly makes a locally best choice. It is correct only when the problem has the required greedy-choice structure.

## Learning goals

- explain the technique in plain language;
- recognize suitable problem patterns;
- implement a clear C# solution;
- estimate time and space complexity; and
- test edge cases.
