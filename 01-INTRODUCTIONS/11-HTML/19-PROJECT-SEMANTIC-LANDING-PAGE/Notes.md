# Project — Semantic Landing Page — Notes

Complete landing page with hero, features, workflow, FAQ, call to action, and footer.

## Professional principles

- HTML describes structure and meaning.
- Prefer native semantic elements.
- Separate HTML from CSS and JavaScript.
- Keep source readable and consistently indented.
- Treat accessibility as part of correct HTML.
- Inspect source and DOM when debugging.
- Validate before committing.

## Capstone mindset

The document should remain understandable and usable before CSS is added. Structure the information first, then style it later.
