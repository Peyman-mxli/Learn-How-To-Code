# Project 02 — Todo App

A command-line task manager written in Python.

## Features

- add tasks;
- list tasks;
- mark tasks complete;
- delete tasks;
- reject empty titles;
- validate task numbers.

## Run

```bash
python main.py
```

No third-party dependencies are required.

## Scope

This version keeps tasks in memory. Closing the program clears the list. A future extension can persist tasks with JSON or SQLite.
