# Project 01 — CLI Calculator

A small Python command-line calculator demonstrating structured input handling and reusable arithmetic functions.

## Features

- addition;
- subtraction;
- multiplication;
- division;
- division-by-zero protection;
- numeric input validation; and
- repeat-until-exit workflow.

## Run

```bash
python main.py
```

No third-party packages are required.
