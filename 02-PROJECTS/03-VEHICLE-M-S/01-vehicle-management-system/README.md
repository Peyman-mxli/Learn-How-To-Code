# Vehicle Management System — Implementation

The executable implementation is located in `vehiculos_dashboard/`.

```text
vehiculos_dashboard/
├── main.py
├── app/
│   └── modelos/
│       ├── vehiculo.py
│       ├── automovil.py
│       ├── motocicleta.py
│       ├── camion.py
│       └── bicicleta.py
├── static/
└── templates/
```

Run:

```bash
cd vehiculos_dashboard
python main.py
```
