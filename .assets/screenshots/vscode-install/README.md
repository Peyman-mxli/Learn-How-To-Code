## 📘 Overview

This folder contains the screenshots I use to explain **how to install Visual Studio Code on Windows**.

Each image represents a real step in the installation process and is named in the same order that the steps appear in the installation README.

The goal is simple: a beginner should be able to read the guide, look at the screenshot, and immediately understand what should appear on the screen and what action to take next.
